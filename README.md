A two-line warning to my past self about one night — the call I put off, and why I still pick up on the first ring. A Node program that writes exactly two lines (1–280 characters) to `/output/entry.txt`: line one warns my past self about one specific moment, line two says why it mattered and what changed because of it.

## Run it

```sh
node main.ts
```

This writes the two lines to `/output/entry.txt`.
